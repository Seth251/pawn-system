# ប្រព័ន្ធបញ្ចាំ (Khmer Pawn System)

កម្មវិធីគ្រប់គ្រងការបញ្ចាំសម្រាប់ប្រើលើទូរស័ព្ទ និងកុំព្យូទ័រ។ មិនចាំបាច់ដំឡើង dependency ឬបង្កើត server ទេ។ ទំព័រទាំងអស់ជាភាសាខ្មែរ។

## របៀបប្រើ

1. ចុច **បន្ថែមការបញ្ចាំ** ហើយបញ្ចូលឈ្មោះអតិថិជន ទំនិញ ប្រាក់ដែលឱ្យខ្ចី អត្រាការប្រាក់ ថ្ងៃឱ្យខ្ចី និងគណនី Telegram។ ចុច **ស្កេន QR** ដើម្បីប្រើកាមេរ៉ា ឬជ្រើសរូបភាព QR ពីឧបករណ៍។
2. កម្មវិធីគណនាការប្រាក់ប្រចាំខែ។ ឧទាហរណ៍ ប្រាក់ដើម $100 អត្រា 3% គឺ $3 ក្នុងមួយខែ។
3. បើកផ្ទាំង **ត្រូវរំលឹក** ដើម្បីមើលអ្នកដល់ថ្ងៃបង់ ឬហួសថ្ងៃបង់។ ចុច **បើក Telegram** ដើម្បីបើកការជជែកជាមួយសាររំលឹកជាភាសាខ្មែរដែលបានត្រៀមរួច។ ពិនិត្យហើយចុចផ្ញើដោយខ្លួនឯង។
4. ពេលទទួលការប្រាក់ ចុច **កត់ត្រាប្រាក់បានបង់**។ ការកត់ត្រាមួយដងសម្រាប់មួយខែ។ ប្រាក់ដើមមិនត្រូវកាត់បន្ថយឡើយ។
5. ពេលសងប្រាក់ដើម និងការប្រាក់ដែលនៅសល់ ព្រមទាំងប្រគល់ទំនិញវិញ ចុច **បញ្ចប់ការបញ្ចាំ**។

ថ្ងៃបង់បន្ទាប់គិតតាមថ្ងៃឱ្យខ្ចីដើម។ បើថ្ងៃនោះមិនមានក្នុងខែណាមួយ កម្មវិធីប្រើថ្ងៃចុងក្រោយនៃខែនោះ។ ខែដែលមិនទាន់កត់ត្រាបង់នៅតែបង្ហាញថាដល់ថ្ងៃបង់។

## ផ្សាយលើ GitHub Pages

ក្នុង GitHub repository នេះ ចូល **Settings → Pages → Build and deployment**។ ជ្រើស **Deploy from a branch**, បន្ទាប់មកជ្រើស branch **main** និង folder **/(root)** ហើយចុច **Save**។ ឯកសារ `index.html` ស្ថិតនៅក្នុង root រួចហើយ។ មិនត្រូវជ្រើស README ជាទំព័រដើមទេ។

## ទិន្នន័យ និងឯកជនភាព

ទិន្នន័យអតិថិជនរក្សាទុកក្នុង browser របស់ឧបករណ៍នីមួយៗតែប៉ុណ្ណោះ។ GitHub មានតែកូដកម្មវិធី មិនមានកំណត់ត្រាអតិថិជនឡើយ។ ទិន្នន័យមិន sync រវាងទូរស័ព្ទនិងកុំព្យូទ័រទេ។ ចុច **ទាញយកទិន្នន័យ** ជាប្រចាំ ហើយប្រើ **ស្ដារទិន្នន័យ** ដើម្បីយកមកវិញ ឬផ្ទេរទៅឧបករណ៍ផ្សេង។ ការស្ដារនឹងជំនួសទិន្នន័យនៅលើឧបករណ៍នោះ។ អាចស្ដារឯកសារ JSON ដែលបាន export ពី PawnDesk មុនបានផងដែរ។

ការជូនដំណឹងបង្ហាញពេលបើកកម្មវិធី ហើយពិនិត្យថ្ងៃជាថ្មីពេលបើកទំព័រវិញ។ កម្មវិធីមិនផ្ញើ Telegram ដោយស្វ័យប្រវត្តិ និងមិនផ្ញើ push notification នៅពេលបិទកម្មវិធីឡើយ។ QR ត្រូវជាតំណគណនីផ្ទាល់ `t.me/username` ឬ `t.me/+លេខទូរស័ព្ទអន្តរជាតិ`។ QR ចូលក្រុម និង QR ចូលគណនី Telegram មិនអាចកំណត់អត្តសញ្ញាណអតិថិជនបានទេ។ កាមេរ៉ាត្រូវការការអនុញ្ញាតនៅក្នុង browser; អ្នកអាចជ្រើសរូបភាព QR ឬវាយគណនីដោយដៃ។

## ការត្រួតពិនិត្យ

បើមាន Node.js អាចរត់ `npm ci` ហើយ `npm run check` ដើម្បីពិនិត្យការបញ្ចូលព័ត៌មាន ថ្ងៃចុងខែ ប្រវត្តិការបង់ ការនាំចូលទិន្នន័យ និងការអាន Telegram QR។ GitHub Pages មិនត្រូវការ `npm ci` ទេ ព្រោះបណ្ណាល័យស្កេន QR ស្ថិតក្នុង `vendor/` រួចហើយ។
