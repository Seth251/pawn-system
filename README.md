# ប្រព័ន្ធបញ្ចាំ (Khmer Pawn System)

កម្មវិធីគ្រប់គ្រងការបញ្ចាំសម្រាប់ប្រើលើទូរស័ព្ទ និងកុំព្យូទ័រ។ មិនចាំបាច់ដំឡើង dependency ឬបង្កើត server ទេ។ ទំព័រទាំងអស់ជាភាសាខ្មែរ។

## របៀបប្រើ

1. ចុច **បន្ថែមការបញ្ចាំ** ហើយជ្រើសប្រភេទទំនិញដូចជា មាស ខ្សែក ចិញ្ចៀន ឬម៉ូតូ។ បញ្ចូលឈ្មោះអតិថិជន ប្រាក់ដែលឱ្យខ្ចី រូបិយប័ណ្ណ ថ្ងៃឱ្យខ្ចី និងការប្រាក់។ ប្រភេទ **ផ្សេងៗ** ត្រូវការឈ្មោះទំនិញ។ សម្រាប់ទំនិញមាស សូមធីកថាជាមាស ហើយបញ្ចូលទម្ងន់ជាក្រាម ជី ឬតម្លឹង។ កម្មវិធីមិនបម្លែងទម្ងន់ទេ។ អ្នកអាចកត់ត្រាស្ថានភាពទំនិញ ទីតាំងរក្សាទុក និងលេខសម្គាល់។ គណនី Telegram អាចទុកទំនេរ ហើយអាចបញ្ចូលដោយស្កេន QR ឬជ្រើសរូបភាព QR។
2. ជ្រើស **ភាគរយ (%)** ឬ **ចំនួនប្រាក់ថេរ** ក្នុងមួយខែ។ ឧទាហរណ៍ $100 ក្នុងអត្រា 3% គឺ $3 ក្នុងមួយខែ។ ប្រាក់រៀលទទួលតែចំនួនគត់ ហើយស្ថិតិ USD និង KHR បង្ហាញដាច់ដោយឡែក ដោយមិនបម្លែងអត្រាប្រាក់។
3. បើកផ្ទាំង **ត្រូវរំលឹក** ដើម្បីមើលអ្នកដល់ថ្ងៃបង់ ឬហួសថ្ងៃបង់។ ចុច **បើក Telegram** ដើម្បីបើកការជជែកជាមួយសាររំលឹកជាភាសាខ្មែរដែលបានត្រៀមរួច។ ពិនិត្យហើយចុចផ្ញើដោយខ្លួនឯង។
4. ចុច **កត់ត្រាការបង់ប្រាក់** ហើយជ្រើស **ការប្រាក់** ឬ **ប្រាក់ដើម**។ អាចកត់ត្រាចំនួនតិចជាងប្រាក់ត្រូវបង់ ហើយកម្មវិធីបង្ហាញចំនួននៅសល់។ ការបង់ប្រាក់ដើមបន្ថយប្រាក់ដើមនៅសល់ ប៉ុន្តែមិនប្ដូរការប្រាក់ប្រចាំខែដែលបានព្រមព្រៀងដោយស្វ័យប្រវត្តិទេ។ អ្នកអាចកែការចុចខុសដោយលុបការបង់ចុងក្រោយ។
5. ចុច **មើល / បោះពុម្ពបង្កាន់ដៃ** ដើម្បីពិនិត្យព័ត៌មានកិច្ចសន្យា និងប្រវត្តិបង់ប្រាក់ ហើយបោះពុម្ព ឬរក្សាទុកជា PDF ពីកម្មវិធីរុករក។
6. ពេលអតិថិជនបានសងប្រាក់ដើម និងការប្រាក់ដល់ថ្ងៃបង់ដែលនៅសល់ ព្រមទាំងទទួលទំនិញវិញ ចុច **បញ្ចប់ការបញ្ចាំ**។ ការបញ្ជាក់នេះកត់ត្រាចំនួននៅសល់ជាការបង់ពេលបញ្ចប់។

ថ្ងៃបង់បន្ទាប់គិតតាមថ្ងៃឱ្យខ្ចីដើម។ បើថ្ងៃនោះមិនមានក្នុងខែណាមួយ កម្មវិធីប្រើថ្ងៃចុងក្រោយនៃខែនោះ។ ការបង់ការប្រាក់តិចជាងមួយខែទុកឱ្យចំនួននៅសល់បង្ហាញជាបន្ត។

## ផ្សាយលើ GitHub Pages

ក្នុង GitHub repository នេះ ចូល **Settings → Pages → Build and deployment**។ ជ្រើស **Deploy from a branch**, បន្ទាប់មកជ្រើស branch **main** និង folder **/(root)** ហើយចុច **Save**។ ឯកសារ `index.html` ស្ថិតនៅក្នុង root រួចហើយ។ មិនត្រូវជ្រើស README ជាទំព័រដើមទេ។

## ទិន្នន័យ និងឯកជនភាព

ទិន្នន័យអតិថិជនរក្សាទុកក្នុង browser របស់ឧបករណ៍នីមួយៗតែប៉ុណ្ណោះ។ GitHub មានតែកូដកម្មវិធី មិនមានកំណត់ត្រាអតិថិជនឡើយ។ ទិន្នន័យមិន sync រវាងទូរស័ព្ទនិងកុំព្យូទ័រទេ។ ចុច **ទាញយកទិន្នន័យ** ជាប្រចាំ ហើយប្រើ **ស្ដារទិន្នន័យ** ដើម្បីយកមកវិញ ឬផ្ទេរទៅឧបករណ៍ផ្សេង។ ការស្ដារនឹងជំនួសទិន្នន័យនៅលើឧបករណ៍នោះ។ អាចស្ដារឯកសារ JSON ជំនាន់មុនរបស់កម្មវិធីនេះ និង PawnDesk បាន។ កំណត់ត្រាចាស់នៅមានឈ្មោះទំនិញដដែល ហើយត្រូវបានដាក់ក្នុងប្រភេទ «ផ្សេងៗ» ដើម្បីអ្នកអាចជ្រើសប្រភេទថ្មីពេលកែព័ត៌មាន។

ការជូនដំណឹងបង្ហាញពេលបើកកម្មវិធី ហើយពិនិត្យថ្ងៃជាថ្មីពេលបើកទំព័រវិញ។ កម្មវិធីមិនផ្ញើ Telegram ដោយស្វ័យប្រវត្តិ និងមិនផ្ញើ push notification នៅពេលបិទកម្មវិធីឡើយ។ QR ត្រូវជាតំណគណនីផ្ទាល់ `t.me/username` ឬ `t.me/+លេខទូរស័ព្ទអន្តរជាតិ`។ QR ចូលក្រុម និង QR ចូលគណនី Telegram មិនអាចកំណត់អត្តសញ្ញាណអតិថិជនបានទេ។ កាមេរ៉ាត្រូវការការអនុញ្ញាតនៅក្នុង browser; អ្នកអាចជ្រើសរូបភាព QR ឬវាយគណនីដោយដៃ។

## ការត្រួតពិនិត្យ

បើមាន Node.js អាចរត់ `npm ci` ហើយ `npm run check` ដើម្បីពិនិត្យការបញ្ចូលព័ត៌មាន ថ្ងៃចុងខែ ប្រវត្តិការបង់ ការនាំចូលទិន្នន័យ និងការអាន Telegram QR។ GitHub Pages មិនត្រូវការ `npm ci` ទេ ព្រោះបណ្ណាល័យស្កេន QR ស្ថិតក្នុង `vendor/` រួចហើយ។
